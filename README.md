# flat-rate

A private logbook for a flat-rate automotive technician: the hours flagged off the repair
order next to the hours actually spent, kept by the technician, for the technician.

**Nothing is built yet, and nothing may be.** The project is at stage 3 of the loop in
[CLAUDE.md](../CLAUDE.md) — the assumptions are written down and none has been tested. The
riskiest one is that a technician will record actual time at all. A week of paper decides
that, and gates everything else.

## Run it

Nothing to run. Start by reading [docs/HANDOFF.md](docs/HANDOFF.md), which says where this
is and what happens next.
